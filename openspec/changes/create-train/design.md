## Context

The `train/` Spring Modulith module exists as an empty package. The `trains` table is fully provisioned in PostgreSQL with UUID primary keys (after `V2.0.0` migration). Other modules (`booking`, `route`, `seat`) already reference `train_id` as a UUID foreign key, so the Train aggregate must be accessible as a named interface. The change implements three read/write endpoints following the exact same vertical-slice + DDD patterns used by `user/` and `booking/`.

## Goals / Non-Goals

**Goals:**

- Implement `POST /api/v1.0/trains` — create a new train (ADMIN only)
- Implement `GET /api/v1.0/trains` — paginated list of trains (authenticated)
- Implement `GET /api/v1.0/trains/{id}` — fetch a single train by UUID (authenticated)
- Follow all existing patterns: Result monad, JSend response, vertical-slice module layout, ArchUnit-safe layer separation
- Expose `TrainId` via `@NamedInterface("model")` for safe cross-module reference

**Non-Goals:**

- Update, soft-delete, or deactivate trains
- Manage seats or routes within this change
- Train schedule / timetable management
- Frontend or admin-dashboard UI changes

## Decisions

| # | Decision | Rationale |
|---|----------|-----------|
| 1 | **UUID for `TrainId`**, generated by the database (`DEFAULT uuidv7()`) | Consistent with every other module post-V2 migration; no application-side generation needed at create time |
| 2 | **No `TrainStatus` enum in this change** | The schema only has `train_number`, `name`, `total_seats`, `created_at`; adding a status column is out of scope and would require a new migration |
| 3 | **`TrainCreated` domain event published after create** | Follows the pattern set by `UserRegistered` and `BookingCreated`; enables future modules (notifications, audit) to react without coupling |
| 4 | **`POST /trains` is ADMIN-only; `GET` endpoints require authentication** | Consistent with existing security config where write operations are admin-guarded |
| 5 | **`train_number` uniqueness enforced at both domain and DB levels** | DB unique constraint already exists; domain check via `TrainRepository.existsByTrainNumber()` returns a typed `TrainError.TrainNumberAlreadyExists` before hitting the DB |
| 6 | **`TrainId` model package exposed as `@NamedInterface("model")`** | Allows `booking/` and future modules to safely import `TrainId` without circular dependencies |
| 7 | **Pagination via shared `PageResult<T>` + `SortDirection`** | Reuses existing shared types, identical to user list pagination |

## Risks / Trade-offs

| Risk | Likelihood | Mitigation |
|------|-----------|------------|
| `uuidv7()` DB function not installed in some environments | Low | Already required by V2 migration; documented in local-dev-environment spec |
| ArchUnit violation if `TrainEntity` is placed in domain package | Low | Strict rule: `TrainEntity` lives in `infrastructure/persistence/` only |
| `TrainId` named interface causes accidental coupling | Low | Only exposes the value object record, not the aggregate or repository |
| Race condition on `train_number` uniqueness check | Very low | DB unique constraint is the final guard; domain pre-check reduces error surface |

## Architecture

The `train/` module is a self-contained Spring Modulith vertical slice. No other module is modified; `SecurityConfig` in `user/infrastructure/security/` receives one new `requestMatchers` rule for train endpoints.

```
train/
├── package-info.java                          @ApplicationModule
├── domain/
│   ├── model/
│   │   ├── package-info.java                  @NamedInterface("model")
│   │   ├── Train.java                         Aggregate root
│   │   ├── TrainId.java                       record TrainId(UUID value)
│   ├── event/
│   │   └── TrainCreated.java                  record (implements DomainEvent)
│   ├── repository/
│   │   └── TrainRepository.java               port interface
│   └── errors/
│       └── TrainError.java                    sealed interface
├── application/
│   ├── usecase/
│   │   ├── CreateTrainUseCase.java            @Service @Transactional
│   │   ├── GetTrainByIdUseCase.java           @Service (read-only)
│   │   └── GetTrainsUseCase.java              @Service (read-only, paginated)
│   ├── command/
│   │   └── CreateTrainCommand.java            record
│   └── dto/
│       └── TrainDto.java                      record
└── infrastructure/
    ├── persistence/
    │   ├── TrainEntity.java                   @Entity  table="trains"
    │   ├── TrainJpaRepository.java            extends JpaRepository<TrainEntity, UUID>
    │   ├── TrainRepositoryAdapter.java        @Repository implements TrainRepository
    │   └── TrainEntityMapper.java             @Component
    └── web/
        ├── TrainController.java               @RestController  /api/v{v}/trains
        ├── CreateTrainHttpRequest.java        record + @Valid
        ├── TrainHttpResponse.java             record
        └── TrainRequestMapper.java            @Component
```

## Components

| Component | Responsibility | Location |
|-----------|----------------|----------|
| `Train` | Aggregate root; holds `TrainId`, `trainNumber`, `name`, `totalSeats`, `createdAt`; factory `create()` publishes `TrainCreated` | `domain/model/Train.java` |
| `TrainId` | Type-safe UUID value object; exposed via `@NamedInterface("model")` | `domain/model/TrainId.java` |
| `TrainCreated` | Immutable domain event record published after successful create | `domain/event/TrainCreated.java` |
| `TrainRepository` | Port interface: `save`, `findById`, `findAll(page,size,sort,dir)`, `existsByTrainNumber` | `domain/repository/TrainRepository.java` |
| `TrainError` | Sealed interface: `TrainNumberAlreadyExists`, `TrainNotFound` | `domain/errors/TrainError.java` |
| `CreateTrainUseCase` | Checks uniqueness → creates aggregate → saves → returns `Result<TrainDto, TrainError>` | `application/usecase/CreateTrainUseCase.java` |
| `GetTrainByIdUseCase` | Fetches by `TrainId` → returns `Result<TrainDto, TrainError>` | `application/usecase/GetTrainByIdUseCase.java` |
| `GetTrainsUseCase` | Paginated query → returns `PageResult<TrainDto>` | `application/usecase/GetTrainsUseCase.java` |
| `CreateTrainCommand` | Input record: `trainNumber`, `name`, `totalSeats` | `application/command/CreateTrainCommand.java` |
| `TrainDto` | Output record: `id(UUID)`, `trainNumber`, `name`, `totalSeats`, `createdAt` | `application/dto/TrainDto.java` |
| `TrainEntity` | JPA `@Entity` for table `trains`; fields mirror schema columns | `infrastructure/persistence/TrainEntity.java` |
| `TrainJpaRepository` | Spring Data interface; adds `existsByTrainNumber(String)` | `infrastructure/persistence/TrainJpaRepository.java` |
| `TrainRepositoryAdapter` | Implements `TrainRepository` using `TrainJpaRepository` + `TrainEntityMapper` | `infrastructure/persistence/TrainRepositoryAdapter.java` |
| `TrainEntityMapper` | Maps `TrainEntity` ↔ `Train` domain model | `infrastructure/persistence/TrainEntityMapper.java` |
| `TrainController` | Handles POST, GET-list, GET-by-id; returns `JsendResponse<?>` | `infrastructure/web/TrainController.java` |
| `CreateTrainHttpRequest` | Request record with Jakarta Validation annotations | `infrastructure/web/CreateTrainHttpRequest.java` |
| `TrainHttpResponse` | Response record matching `TrainDto` fields | `infrastructure/web/TrainHttpResponse.java` |
| `TrainRequestMapper` | Maps `CreateTrainHttpRequest` → `CreateTrainCommand`, `TrainDto` → `TrainHttpResponse` | `infrastructure/web/TrainRequestMapper.java` |

## Data Models

```
Train (domain aggregate)
├── id:          TrainId          (wraps UUID)
├── trainNumber: String           (unique, max 20 chars)
├── name:        String           (max 255 chars)
├── totalSeats:  int              (positive)
└── createdAt:   Instant

TrainEntity (JPA, table = "trains")
├── id:          UUID             @Id @Column(updatable=false)
├── trainNumber: String           @Column(unique=true)
├── name:        String
├── totalSeats:  int
└── createdAt:   Instant          @Column(updatable=false)

CreateTrainCommand (application input)
├── trainNumber: String
├── name:        String
└── totalSeats:  int

TrainDto (application output)
├── id:          UUID
├── trainNumber: String
├── name:        String
├── totalSeats:  int
└── createdAt:   Instant

CreateTrainHttpRequest (web input, validated)
├── trainNumber: @NotBlank @Size(max=20) String
├── name:        @NotBlank @Size(max=255) String
└── totalSeats:  @Positive int

TrainHttpResponse (web output)
├── id:          UUID
├── trainNumber: String
├── name:        String
├── totalSeats:  int
└── createdAt:   Instant
```

## Key Flows

### POST /api/v1.0/trains

```
Client
  │  POST /api/v1.0/trains  {trainNumber, name, totalSeats}
  ▼
TrainController.create(@Valid CreateTrainHttpRequest)
  │  mapper.toCommand(request) → CreateTrainCommand
  ▼
CreateTrainUseCase.execute(command)
  │  trainRepository.existsByTrainNumber(command.trainNumber())
  │    └─ true  → return Result.failure(TrainNumberAlreadyExists)
  │
  │  Train.create(TrainId.of(UUID.randomUUID()), ...)
  │    └─ registers TrainCreated domain event
  │
  │  trainRepository.save(train)
  │    └─ TrainRepositoryAdapter → TrainEntityMapper.toEntity()
  │                              → jpaRepository.save()
  │                              → TrainEntityMapper.toDomain()
  │  return Result.success(TrainDto)
  ▼
TrainController
  │  .fold(
  │    success → 201 Created  + Location header + JsendResponse.success(TrainHttpResponse)
  │    failure → errorResponse(TrainError)
  │  )
  ▼
Client
```

### GET /api/v1.0/trains

```
Client
  │  GET /api/v1.0/trains?page=0&size=20&sort=trainNumber&direction=ASC
  ▼
TrainController.list(@RequestParam page, size, sort, direction)
  ▼
GetTrainsUseCase.execute(page, size, sort, direction)
  │  trainRepository.findAll(page, size, sort, direction)
  │    └─ TrainRepositoryAdapter → JpaRepository + PageRequest
  │  return PageResult<TrainDto>
  ▼
TrainController → 200 OK + JsendResponse.success(PageResult<TrainHttpResponse>)
  ▼
Client
```

### GET /api/v1.0/trains/{id}

```
Client
  │  GET /api/v1.0/trains/{uuid}
  ▼
TrainController.getById(@PathVariable UUID id)
  ▼
GetTrainByIdUseCase.execute(TrainId.of(id))
  │  trainRepository.findById(trainId)
  │    └─ empty → return Result.failure(TrainNotFound)
  │    └─ found → return Result.success(TrainDto)
  ▼
TrainController
  │  .fold(
  │    success → 200 OK + JsendResponse.success(TrainHttpResponse)
  │    failure → 404 Not Found + JsendResponse.fail(...)
  │  )
  ▼
Client
```

## Error Handling

| Error | HTTP Status | JSend Status | Error Code |
|-------|-------------|--------------|------------|
| `TrainNumberAlreadyExists` | 409 Conflict | `fail` | `TRAIN_NUMBER_ALREADY_EXISTS` |
| `TrainNotFound` | 404 Not Found | `fail` | `TRAIN_NOT_FOUND` |
| Validation failure (`@Valid`) | 400 Bad Request | `fail` | `VALIDATION_ERROR` |
| Unauthenticated | 401 Unauthorized | `fail` | (Spring Security) |
| Non-ADMIN on POST | 403 Forbidden | `fail` | (Spring Security) |

## Boundary Definitions

| Boundary | Direction | Notes |
|----------|-----------|-------|
| `train::model` (`TrainId`) | Exported to other modules | Via `@NamedInterface("model")` in `domain/model/package-info.java` |
| `SecurityConfig` (user module) | Modified externally | Add two `requestMatchers`: POST `/api/*/trains/**` → ADMIN; GET `/api/*/trains/**` → authenticated |
| `trains` DB table | Read/Write | No schema change needed; UUIDs already in place |
| `ApplicationEventPublisher` | Outbound | `TrainCreated` event published after successful create |
